## 1. プロジェクト概要

### 背景・目的

| 項目 | 内容 |
|------|------|
| 現状の課題 | Booking.com などのOTA経由予約が主で、**約15%の手数料**が発生している |
| 解決策 | 自社公式サイトを制作し、**直接予約の受け皿**を作る |
| 期待効果 | 手数料削減・ブランド認知向上・顧客との直接関係構築 |

### ゴール

- OTA手数料を削減し、**収益率を改善**する
- 「Good Day Mate」および各施設の**ブランドイメージを確立**する
- 自社サイトから**直接予約が完結**できる仕組みを作る

## 3. 各ページの詳細仕様

### 3-1. コーポレートトップページ（`/`）

トップページは以下の**8つのセクション**で構成されます。

---

#### ① ヘッダー（固定ナビゲーション）

- 画面最上部に常時固定表示
- **スクロール前**: 透明背景（ヒーロー画像に溶け込む）
- **スクロール後**: 白背景に切り替わり、ロゴ・メニューが明確に見える
- **ロゴ**:「Good Day Mate」（セリフ体）＋「Okinawa Luxury Stay」（サブテキスト）
- **メニュー項目**: 会社概要 ／ 施設紹介 ／ 事業内容 ／ お問い合わせ ／ 予約する（ボタン）
- **スマートフォン対応**: ハンバーガーメニューでスライド表示

---

#### ② ヒーローセクション

- **全画面表示**（画面いっぱいに広がる写真）
- 沖縄の美しい海・施設の写真を背景に使用
- **キャッチコピー**: 「沖縄の特別な体験を、あなたに」
- **サブコピー**: 「日常を忘れる、プライベートな空間。Good Day Mateが贈る、最高の沖縄ステイ。」
- **ボタン2つ**: 「施設を見る（ゴールド）」 ／ 「会社について（テキストリンク）」
- **スクロール誘導**: 下部にスクロールを促すアニメーション

---

#### ③ 簡易予約バー（ヒーロー直下）

- ヒーロー直下に横並びで表示
- **入力項目**: チェックイン日 ／ チェックアウト日 ／ 人数
- **ボタン**: 「空き確認」
- 予約エンジン（Beds24）と接続することで機能

```
[ チェックイン日 ]  [ チェックアウト日 ]  [ 人数 ▼ ]  [ 空き確認 → ]
```

---

#### ④ 実績数値バー

信頼感を高める数字を4つ横並びで表示

---

#### ⑤ 施設紹介セクション

## 5. 予約システム仕様

### 方針：**Beds24（外部予約エンジン）を導入**

自作 vs 外部導入の比較：

| 比較項目 | 自作 | Beds24（推奨） |
|----------|------|----------------|
| 初期費用 | 開発工数 5〜10日 | 無料 |
| 月額費用 | サーバー代のみ | **$4〜$20**（約600〜3,000円） |
| OTA連携 | 別途実装が必要 | **Booking.com・Airbnb 対応済み** |
| 決済機能 | Stripe等を別途導入 | **内蔵** |
| 在庫管理 | 自作 | OTAとリアルタイム同期 |
| 推奨時期 | 予約が月100件超になったら | **今すぐ導入可** |

### Beds24 導入の流れ

1. Beds24 でアカウント作成（無料）
2. 物件情報・カレンダーを設定
3. Beds24 の予約ウィジェットコードを当サイトの予約フォームに差し込む
4. Booking.com・Airbnb と連携し、カレンダーを一元管理

### 直接予約の訴求

- 「**直接予約で最低価格保証**」のバナーを予約ウィジェット横に常時表示
- OTAより最大15%安いことを明記し、直接予約を促進

## 6. 技術仕様

| 項目 | 採用技術 | 選定理由 |
|------|---------|---------|
| フレームワーク | **Next.js 14** | SEO対策・高速表示・Vercel連携 |
| スタイリング | **Tailwind CSS** | 開発速度・デザイン一貫性 |
| ホスティング | **Vercel**（推奨） | Next.js特化・CDN自動・無料プランあり |
| 画像最適化 | Next.js Image | 自動WebP変換・遅延読み込み |
| アニメーション | CSS Transition + Intersection Observer | 軽量・パフォーマンス優先 |
| フォント | Google Fonts | 無料・高品質 |

### 対応デバイス

- **PC**: 1280px以上
- **タブレット**: 768px〜1279px
- **スマートフォン**: 375px〜767px（全セクションをモバイル最適化済み）

### SEO対策

- 各ページに適切なタイトル・ディスクリプション・OGP設定
- 構造化データ（施設情報・レビュー）の設定
- サイトマップの自動生成
- ページ表示速度の最適化（画像圧縮・遅延読み込み）

## 7. 費用概算

### 初期費用

| 項目 | 費用 |
|------|------|
| ドメイン取得（例: gooddaymate.jp） | 約1,500〜3,000円/年 |
| SSL証明書 | 無料（Vercelに含む） |
| 施設写真撮影（プロカメラマン） | 50,000〜150,000円（任意） |
| **合計** | **約50,000〜155,000円** |

### 月額ランニングコスト

| 項目 | 費用 |
|------|------|
| Vercel（ホスティング） | 無料〜$20/月（約0〜3,000円） |
| Beds24（予約エンジン） | $4〜$20/月（約600〜3,000円） |
| ドメイン | 約125〜250円/月 |
| **合計** | **約1,000〜6,000円/月** |

### 投資回収シミュレーション

- 月間予約10件・平均客単価4万円の場合
- OTA経由：手数料15% → **月6万円の手数料負担**
- 自社サイト経由に1件でも移行すれば → **月6,000円のサイト維持費を大幅に上回る**

## 1. プロジェクト概要

### 背景・目的

| 項目 | 内容 |
|------|------|
| 現状の課題 | Booking.com などのOTA経由予約が主で、**約15%の手数料**が発生している |
| 解決策 | 自社公式サイトを制作し、**直接予約の受け皿**を作る |
| 期待効果 | 手数料削減・ブランド認知向上・顧客との直接関係構築 |

### ゴール

- OTA手数料を削減し、**収益率を改善**する
- 「Good Day Mate」および各施設の**ブランドイメージを確立**する
- 自社サイトから**直接予約が完結**できる仕組みを作る

### ROIシミュレーション

- 月間予約10件・平均客単価4万円 → OTA手数料15% = **月6万円の負担**
- 自社サイト経由に1件移行するだけで → **月6,000円の維持費を大幅に上回る**

## 7. デプロイ手順

### 前提条件

- Node.js 18以上インストール済み
- GitHubリポジトリ: `20030824s-max/gooddaymate`
- Cloudflare Pagesプロジェクト: `gooddaymate`（要作成）

### Cloudflare Pages プロジェクト作成手順

1. [Cloudflare Dashboard](https://dash.cloudflare.com) にログイン
2. 左メニュー「Workers & Pages」→「Pages」→「Create application」
3. 「Connect to Git」→ GitHubの `20030824s-max/gooddaymate` を選択
4. 以下を設定：
   - **プロジェクト名**: `gooddaymate`
   - **本番ブランチ**: `claude/booking-system-website-Dx0T3`
   - **ビルドコマンド**: `npm run build`
   - **出力ディレクトリ**: `out`
5. 「Save and Deploy」をクリック

### ローカル開発

```bash
# 依存パッケージインストール
npm install

# 開発サーバー起動（http://localhost:3000）
npm run dev

# 本番ビルド（静的HTML生成 → out/ディレクトリ）
npm run build

# ビルド確認
npx serve out
```

### デプロイ（自動）

`claude/booking-system-website-Dx0T3` ブランチへのpushで自動デプロイ。
